# Исходные материалы

## Фотографии Ивана Новикова

Положите сюда исходные снимки, затем скопируйте подготовленные файлы в `public/images`:

| Файл в `public/images` | Какой снимок | Где используется |
|---|---|---|
| `ivan-novikov-portrait.jpg` | Портрет анфас на светлом фоне, серьёзный | Первый экран главной, страница «О компании» |
| `ivan-novikov.jpg` | Полуоборот, улыбается, светлый фон | Блок руководителя на главной и на странице «О компании» |

Пока файлов нет, на их месте выводится аккуратная типографическая заглушка —
вёрстка не ломается и не прыгает. Как только файлы появятся, следующая сборка
подхватит их автоматически: править код не нужно.

Рекомендации: вертикальный кадр (примерно 2:3), ширина от 1200 px, светлый фон.
Next.js сам сделает WebP и AVIF нужных размеров.
