# Интернет-эквайринг ВТБ: соответствие требованиям

Документ показывает, где на сайте `pravstrateg.ru` выполнено каждое требование
Банка ВТБ к интернет-магазину, и содержит заготовку ответов на чек-лист опроса
клиента. Его можно приложить к заявке или использовать как чек-лист перед подачей.

**Выбранный способ подключения — оплата по платёжной ссылке.** По чек-листу
банка: «если Клиенту необходима только оплата по платёжной ссылке (ПС),
то интеграция не требуется и тестирование проходить не нужно. Формирование ПС
происходит в ЛК по ИЭ в Интернет-банке».

Это решение снимает необходимость в интеграции по API, тестировании с банком
и приёме данных карт на стороне сайта.

## Заготовка ответов на чек-лист опроса клиента

Проверить и дополнить перед отправкой в банк.

**1. Какой ресурс подключается**
Сайт `https://pravstrateg.ru`.

**2. Подключён ли ресурс к интернет-эквайрингу сейчас**
Нет, подключение первичное. Действующего интегратора или сервис-провайдера нет.

**3. Тип сайта**
Самописный: Next.js, размещается на собственном сервере. CMS не используется.
При этом интеграция по API **не требуется** — см. пункт 5.

**4. Потребность в фискализации и онлайн-кассе**
Онлайн-кассы нет. Требуется консультация о возможностях банка.
Банк рекомендует приобретать кассу после перевода заявки в ФРКК в статус
«Исполнена», поэтому решение откладывается до согласования подключения.

**5. Дополнительные функции**
Нужна **только оплата по платёжной ссылке**. Рекурренты и оплата по сохранённой
карте не требуются. Согласно чек-листу банка, при этом варианте интеграция
и тестирование не нужны, а ссылки формируются в личном кабинете.

**6. Количество доступов в личный кабинет и ролевая модель**
Один доступ, ролевая модель не требуется. Достаточно личного кабинета
в Интернет-банке ВТБ Бизнес.

## Почему выбрана оплата по ссылке

Стоимость юридических услуг определяется индивидуально после изучения документов:
дела с одинаковым названием отличаются по объёму в разы. Оплата по ссылке
позволяет выставлять клиенту точную согласованную сумму, а не подгонять задачу
под фиксированный прайс.

Дополнительно это снижает риски: реквизиты карт не проходят через сайт вовсе,
поэтому требования PCI DSS к нашей стороне не возникают.

## Устранённые расхождения

В Приложении №1 к политике обработки персональных данных была указана цель
«Направление электронного чека при оплате через сервис Робокасса». Робокасса
не подключается — эквайринг оформляется в ВТБ. Формулировка исправлена
на «Направление электронного чека при оплате банковской картой»: название
провайдера намеренно не указывается, чтобы текст оставался верным при любом
выборе платёжного сервиса и онлайн-кассы. Правовое основание по 54-ФЗ, объём
данных и срок хранения оставлены без изменений.
